# M3 élő térkép

A **Metro Line – M3 Automatic metro simulator** Roblox-játék metróinak élő térképe.

👉 **https://bkvbuszozo0108-alt.github.io/m3-elo-terkep/**

- A játék szervere másodpercenként kétszer elküldi a metrók helyét (Firebase Realtime Database).
- Az oldal minden képkockán a sebességből számolja a pillanatnyi helyet, így a metrók folyamatosan mozognak a valódi Budapest-térképen.
